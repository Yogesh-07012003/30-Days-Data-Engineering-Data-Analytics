# Day 5 — Sales Data Analyzer 📊

## Project Overview

A Python mini project that reads sales data from a CSV file and performs basic sales analysis.

## Features

* Calculate total sales
* Calculate average sales
* Identify the top-selling product
* Analyze sales by region
* Analyze monthly sales
* Read and process CSV data
* Perform data aggregation using Python dictionaries

## Technologies Used

* Python
* CSV
* Dictionary
* List
* `collections.defaultdict`
* `datetime`

## Project Structure

```text
Day05/
├── sales_data.csv
├── sales_analyzer.py
└── README.md
```

## How to Run

1. Clone the repository.

2. Navigate to the Day05 folder:

```bash
cd Day05
```

3. Run the Python program:

```bash
python sales_analyzer.py
```
